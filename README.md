# macci-ornek-ios

[MacCI](https://macci.app) için herkese açık örnek repo. Küçük bir Swift paketi ve macOS üzerinde derleyip test eden bir iş akışı içerir.

İş akışında bilerek **eşzamanlılık denetimi ve önbellek yok**; MacCI bunları bulup taslak PR olarak önerir, birleştirince etkisini ölçer. Public repoda GitHub Actions ücretsizdir.
